# Glossary

**USMTF message** — A source message from which ship-event information has been extracted upstream; Watch Desk displays the message and extracted information without parsing it.
**Message record** — A source message with identifying information, raw text, processing status, and links to its extracted events.
**Extracted event** — A scheduled activity associated with a source message, including its title, unit, location, times, status, and available supporting source lines.
**Zulu/UTC** — The common time reference used for all displayed schedules and calendar calculations.
**Revised event** — An event whose extracted schedule has changed, with previous times shown when available.
**Needs review** — A record containing incomplete or unresolved schedule information that must not be presented as a fully timed calendar event.
**Draft acknowledgement** — An editable, saved response referencing a message that has not been sent.
**Priority** — Chronological order by the soonest event start, not message precedence.
